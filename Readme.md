Esto es Tenebrarium, un juego RPG estilo DND
------------------------------------------------------
Caracteristicas:
1.-Combate por turnos (con artes de los enemigos y jugador)
2.-Inventario por espacios de objetos
3.-Eventos como trampas en las dungeons
4.-Sistemas de Quest por misiones secundarias
5.-3 clases; Guerrero, Mago, Ranger
-------------------------------------------------------
UI/UX
Interfaz de usuario por bloques
Mapa renderizado con caracteres ASCII
Guardado local (json)
Los artes de los personajes se renderizarian usando PNG o JPG dentro de un recuadro
-------------------------------------------------------
